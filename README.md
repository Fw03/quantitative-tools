# 量化观察台

Python 3.10+，仅使用标准库。A 股日线策略研究、CSV 股票池筛选、买卖信号、历史虚拟交易、风控、月度收益和 JSON 导出。**不保证月收益 5%–10%，不连接券商，不自动实盘交易。**

```bash
cd /workspace/quantitative-tools
python3 -m unittest discover -s tests -v
python3 app.py --port 8000
```

服务绑定 127.0.0.1。使用可访问该服务的本地浏览器查看界面；云环境接入方式取决于平台提供的端口访问能力。

默认运行固定随机种子的合成行情，用于演示，不能作为投资依据。导入真实行情 CSV：

```csv
symbol,date,open,high,low,close,volume
600000,2025-01-02,10,10.2,9.9,10.1,1000000
```

每股至少 62 根日线才能产生信号，建议至少 2 年历史数据。列名固定，代码按字符串读取，日期 ISO 格式；重复记录与非法 OHLC 会被拒绝。上传仅用于本次请求，不写入磁盘。一次最多 500 只股票、10MB 请求。

策略：20 日突破、20/60 日均线趋势和 20 日动量，收盘信号在下一可交易日开盘成交；100 股整数手，默认单边手续费 0.03%、滑点 0.1%、卖出印花税 0.05%。默认收盘止损/移动止盈 8%，单仓不超过 20%，初始止损预算不超过权益 1%；组合回撤 15% 后停止买入并安排次日清仓。止损不保证成交价，跳空可能扩大亏损。回测结束时持仓按末次收盘价估值，不强行平仓。

界面展示历史回测重建的虚拟账户，不是持久化模拟券商。桌面通知需浏览器授权且页面运行策略，不自动拉取或定时监控实时行情。刷新后行情与账户不保留，只保存非敏感参数。

## 使用边界与后续研究

未接入实时行情、券商、邮件或聊天推送。模型未覆盖涨跌停、ST/退市规则、分红送转、最低佣金和市场冲击。零成交量顺延，缺失交易日按下一可用日处理，异步行情需核对最后日期。不要将严重缺失的数据直接用于交易决策。

真实评估应使用含退市股票的历史股票池，检查复权与未来信息，分离训练期和样本外测试期，并进行滚动验证与不同成本压力测试。不要仅根据累计收益或少量胜率优化参数。页面显示整段样本回测，不声称样本外有效。

HTTP API：GET /health；POST /api/run，JSON 参数 `csv`（可选）、`capital`、`fee`、`slippage`、`stop`、`max_positions`。不部署到公开网络；当前版本无用户认证。
