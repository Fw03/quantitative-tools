# 量化观察台

面向 A 股的轻量量化研究工具：股票与行情获取、策略筛选、虚拟成交、样本外对比、风险分析和可复跑实验记录。仅生成提醒与模拟交易，不连接券商下单。**月收益 5%–10% 只是研究目标，没有收益保证。**

设计参考 [Qlib](https://github.com/microsoft/qlib)、[Backtrader](https://github.com/mementum/backtrader)、[VeighNa](https://github.com/vnpy/vnpy)、[Freqtrade](https://github.com/freqtrade/freqtrade)。这是独立实现，并非这些框架的集成；设计依据、指标公式和限制见 [开源框架参考](docs/OPEN_SOURCE_DESIGN.md)。

## 启动与验证

Python 3.10+，应用只依赖标准库：

```bash
cd /workspace/quantitative-tools
python3 -m unittest discover -s tests -v
python3 app.py --port 8000
```

服务只绑定本地 `127.0.0.1`。通过平台提供的端口访问能力或本地浏览器访问，不建议直接公开部署（无登录认证）。加载页面只加载记录和报价，不会自动创建回测或发出交易通知。

HTTP 集成验证需要允许本地 socket：

```bash
python3 -m unittest discover -s tests -p 'integration_*.py' -v
```

可选浏览器测试需要额外安装开发工具 Playwright 和 Chromium；本云实例已有，应用运行不需要：

```bash
python3 -m unittest discover -s tests -p 'browser_*.py' -v
```

## 使用流程

1. 选择自动行情、CSV 或合成演示数据；自动行情输入 1–30 只六位 A 股代码。
2. 选择趋势突破或双均线交叉，设置均线周期、突破/动量周期和阈值，以及资金、交易成本与止损。
3. 点击“运行策略”，查看净值与股票池基准、买卖提醒、持仓、月度收益和成交记录。
4. 点击“两策略样本外对比”，对同一股票池与参数按时间切分前 70% / 后 30%，查看收益、回撤、夏普、超额和截断检查；至少 160 个交易日。
5. 在实验记录中查看、导出或复跑快照。重启后记录仍保留；复跑使用旧行情和当前代码，不联网获取新数据。

趋势突破：收盘超过此前 N 日最高价，价格高于短均线，短均线高于长均线，N 日动量超过阈值；跌破短均线退出。双均线：短均线上穿长均线入场，短均线低于长均线退出。默认周期 20/60，动量阈值 3%。

两策略复用收盘信号、次日开盘成交机制，100 股整数手；默认单边佣金 0.03%、滑点 0.1%、卖出印花税 0.05%。单仓不超过 20%，初始止损预算不超过权益 1%，默认收盘止损/移动回撤 8%；组合回撤 15% 后清仓并停止买入。跳空可使损失超过预算，零成交量延后成交。

样本外账户独立启动；之前行情仅用于预热指标，不继承持仓或待成交订单。不会自动调参。重复根据样本外结果调参会污染评估，不是未见数据验证。

## 股票列表、报价与日线

- 东方财富公开股票列表，按页获取沪深北 A 股，可按名称或代码搜索；页面展示前 100 条匹配，缓存 6 小时。
- 腾讯公开报价，显示报价时间、距报价秒数与缺失代码，缓存 30 秒。可勾选每 60 秒更新，后台标签页暂停请求；非交易时段为末次报价，可能延迟。
- 腾讯前复权日线，缓存 15 分钟，剔除北京时间当天避免未收盘数据。任意选中股票日线失败时不进行部分回测，不回退演示数据。北交所个股可能没有可用的前复权日线。

需要允许以下 HTTPS 域名，保留继承代理与 TLS 验证：

- `82.push2.eastmoney.com`
- `qt.gtimg.cn`
- `web.ifzq.gtimg.cn`

在线验证状态：当前实例对上述域名返回代理 403；已保存白名单配置草稿，应用网络配置后仍需重新验证真实股票列表、报价及日线。单元/接口/浏览器测试不等于数据源在线验证。公开数据源无 API Key 要求，但稳定性与授权范围以提供方为准。

CSV 示例（列名固定）：

```csv
symbol,date,open,high,low,close,volume
600000,2025-01-02,10,10.2,9.9,10.1,1000000
```

代码按字符串读取，日期 ISO 格式。重复日期与非法 OHLC 拒绝导入。默认策略至少 62 根日线，自定义长周期需更长历史，建议至少两年。CSV 支持最多 500 只，策略对比最多 100 只；请求不超过 10MB。CSV 原文不直接保存，成功实验会保存解析后的统一行情快照。

合成演示数据是固定种子模拟的 8 只股票、520 个交易日，不能作为真实选股或收益证据。

## API

- `GET /health`：服务健康状态。
- `GET /api/strategies`：策略列表与默认参数。
- `GET /api/stocks?q=平安`：股票列表搜索。
- `GET /api/quotes?symbols=600000,000001`：最新报价。
- `POST /api/run`：单策略回测。
- `POST /api/compare`：两策略对比及截断检查。
- `GET /api/runs`：最近 50 次成功运行。
- `GET /api/runs/{id}`：历史报告。
- `GET /api/runs/{id}/snapshot`：报告、行情快照与参数。
- `POST /api/runs/{id}/replay`，JSON `{}`：使用旧行情复跑，生成新实验记录。

回测/对比请求示例：

```json
{
  "mode": "market",
  "symbols": "600000,000001",
  "days": 500,
  "strategy": "trend_breakout",
  "strategy_params": {"fast": 20, "slow": 60, "lookback": 20, "min_momentum": 0.03},
  "capital": 100000,
  "fee": 0.0003,
  "slippage": 0.001,
  "stop": 0.08,
  "max_positions": 5
}
```

`mode=csv` 另传 `csv` 文本；`mode=demo` 显式运行合成数据。每次成功运行保存原始统一行情快照、参数、报告及指纹到 `data/experiments.sqlite3`，该文件不提交 Git，默认只保留最近 50 次。重要记录请导出备份。复跑使用当前计算代码，不自动切回旧代码。

## 边界

基准为所选股票池等权买入持有，使用碎股、无成本且不再平衡，**不是沪深300等市场指数**。策略年化按 252 个交易日、夏普无风险利率 0；不可计算指标返回 `null`。月度首尾可能不是完整月。具体公式见设计文档。

未处理精确涨跌停、ST/退市、分红送转、最低佣金、部分成交与盘口冲击。前复权不等于时点数据库，当前选择股票池可能有幸存者偏差。截断检查只能检查指定数据与时点，不证明不存在所有未来信息风险。

虚拟账户由回测重建，保存实验不代表持续模拟账户。报价刷新不触发策略；浏览器通知需授权并在页面手动运行策略，不会在恢复历史记录/复跑时发出新通知。未接入后台信号调度、邮件/聊天推送或实盘交易。
