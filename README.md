# 量化观察台

Python 3.10+，仅使用标准库。A 股日线策略研究、CSV 股票池筛选、买卖信号、历史虚拟交易、风控、月度收益和 JSON 导出。**不保证月收益 5%–10%，不连接券商，不自动实盘交易。**

```bash
cd /workspace/quantitative-tools
python3 -m unittest discover -s tests -v
python3 app.py --port 8000
```

服务绑定 127.0.0.1。使用可访问该服务的本地浏览器查看界面；云环境接入方式取决于平台提供的端口访问能力。

默认自动获取 A 股行情；也可切换固定随机种子的合成行情用于演示，演示结果不能作为投资依据。导入真实行情 CSV：

```csv
symbol,date,open,high,low,close,volume
600000,2025-01-02,10,10.2,9.9,10.1,1000000
```

每股至少 62 根日线才能产生信号，建议至少 2 年历史数据。列名固定，代码按字符串读取，日期 ISO 格式；重复记录与非法 OHLC 会被拒绝。上传仅用于本次请求，不写入磁盘。一次最多 500 只股票、10MB 请求。

策略：20 日突破、20/60 日均线趋势和 20 日动量，收盘信号在下一可交易日开盘成交；100 股整数手，默认单边手续费 0.03%、滑点 0.1%、卖出印花税 0.05%。默认收盘止损/移动止盈 8%，单仓不超过 20%，初始止损预算不超过权益 1%；组合回撤 15% 后停止买入并安排次日清仓。止损不保证成交价，跳空可能扩大亏损。回测结束时持仓按末次收盘价估值，不强行平仓。

界面展示历史回测重建的虚拟账户，不是持久化模拟券商。桌面通知需浏览器授权且页面运行策略；勾选自动刷新后每 60 秒更新报价，不自动运行策略。刷新后行情与账户不保留，只保存非敏感参数。

## 使用边界与后续研究

公开报价可能延迟；未接入券商、邮件或聊天推送。模型未覆盖涨跌停、ST/退市规则、分红送转、最低佣金和市场冲击。零成交量顺延，缺失交易日按下一可用日处理，异步行情需核对最后日期。不要将严重缺失的数据直接用于交易决策。

真实评估应使用含退市股票的历史股票池，检查复权与未来信息，分离训练期和样本外测试期，并进行滚动验证与不同成本压力测试。不要仅根据累计收益或少量胜率优化参数。页面显示整段样本回测，不声称样本外有效。

HTTP API：GET /health；POST /api/run，JSON 参数 `csv`（可选）、`capital`、`fee`、`slippage`、`stop`、`max_positions`。不部署到公开网络；当前版本无用户认证。

## 自动获取 A 股股票与行情

界面默认选择“自动下载 A 股日线”。输入六位代码（逗号分隔，每批 1–30 只），点击运行即可获取前复权日线并回测。支持沪市主板/科创板、深市主板/创业板和支持的北交所代码；具体返回范围以数据源为准。历史日线剔除北京时间当天，避免未收盘数据触发日线信号；因此最新策略日期通常为上一交易日。日线缓存 15 分钟。

“获取 / 搜索股票”通过东方财富公开接口按页获取 A 股列表，可按名称或代码查询，列表缓存 6 小时。页面展示前 100 条匹配结果，不自动对全市场批量下载日线。

“刷新最新报价”使用腾讯公开报价，显示股票名称、价格、涨跌幅、报价时间和距报价秒数。可勾选每 60 秒自动刷新，后台标签页暂停请求；不是交易所实时授权行情，可能延迟，非交易时段为末次报价。报价缓存 30 秒，与收盘信号和回测账户分离；刷新报价不会自动下单或重建账户。

公开数据源无需 API Key，稳定性、授权范围与字段可能变化，不提供服务保证。北交所个股可能没有前复权历史数据，接口不支持时会明确失败。任意选中股票日线失败时整次回测失败，不静默丢弃股票或退回合成数据。报价允许部分返回，但会列出缺失代码。缓存仅存于服务内存，进程重启清空；过期缓存不会掩盖网络错误。

云环境需要允许以下 HTTPS 域名（保留代理及 TLS 验证）：

- `82.push2.eastmoney.com`：A 股股票列表
- `qt.gtimg.cn`：最新报价
- `web.ifzq.gtimg.cn`：前复权日线

新增 API：

- `GET /api/stocks?q=平安`：自动获取并搜索股票列表
- `GET /api/quotes?symbols=600000,000001`：报价和时间戳
- `POST /api/run`，JSON 示例 `{"mode":"market","symbols":"600000,000001","days":500}`：自动下载后运行；`mode=csv/demo` 保留原入口。

前复权价格会随除权调整；本版本不是时点复权数据库，不能以历史回测收益证明可实现的实盘收益。

验证状态：数据适配与失败路径使用固定接口样本测试。当前云实例对上述域名返回代理 403，已将白名单添加到配置草稿；在环境设置保存并应用前，真实在线获取尚未验证。
