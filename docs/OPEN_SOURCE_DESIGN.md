### 策略接口

`get_strategy(key, params)` 创建已注册策略。`evaluate(history_prefix)` 只能收到当前时点及之前的日线，输出买入、退出、排序分数、均线和信号原因。新增策略需在 `strategies.py` 注册，并添加信号行为和时间截断回归测试。

- `trend_breakout`：价格突破前 N 日最高价，价格在短均线上方且短均线高于长均线，动量超过阈值；跌破短均线退出。
- `ma_cross`：短均线由下向上穿过长均线入场；短均线低于长均线退出。
- 两者都受仓位预算、收盘止损/移动止盈、组合回撤熔断约束。
- 信号仅在收盘生成，下一可用且有成交量的日线开盘成交；不会用当前收盘信号回填当前开盘成交。
- 当前不是兼容 `bt.Strategy`、Qlib 模型或 VeighNa 策略类的插件运行器，不接受上传任意 Python 执行。

### 研究与偏差检查

策略对比使用同一数据、同一资金和成本，固定按交易日期切成前 70% 样本内、后 30% 样本外。样本外使用独立现金账户，样本内日线只用于指标预热，不继承订单和持仓；首个样本外收盘才生成新信号。不是机器学习训练，也不是自动参数搜索或滚动 walk-forward 验证。

截断检查分别取全样本日期的 50%、75% 运行，比较截至该日期的权益曲线及成交记录。无足够交易的结果为 `inconclusive`，不是“通过”。它借鉴 Freqtrade 对完整与截断运行进行比较的思路，**不等价于 Freqtrade 原命令**，不能检测数据源自身的未来复权或幸存者偏差。

样本外不是持续可重复使用的“调参集”：如果看过结果后继续调参，就应保留新的未见数据。当前不会按收益自动挑选策略，也不宣称存在最佳策略。

### 指标定义

- 年化收益：`(最终权益 / 初始资金) ** (252 / 评估交易日数) - 1`，含未平仓市值，短样本可能夸大。
- 日收益：首日相对初始现金，后续相对前日权益。波动率为日收益样本标准差乘 `sqrt(252)`；夏普以无风险利率 0 计算。
- 最大回撤：权益相对截至当日的最高权益的最大跌幅。卡玛比率为年化收益除以最大回撤绝对值。
- 盈利因子：已平仓交易正收益之和 / 负收益绝对值之和。无亏损时返回 `null`，不报告为无限盈利；无交易胜率也为 `null`。
- 佣金及税来自实际模拟成交；滑点成本单列，已反映在成交价中，不重复从账户扣除。
- 双边换手倍数：买卖名义成交额之和 / 区间平均权益；不是年化单边换手率。平均仓位为日末股票市值 / 权益的平均值。
- 基准：选中股票池的等额初始资金，各股首个有量日开盘买入碎股，之后持有，不再平衡，无交易成本。没有首条行情前保持现金。它**不是沪深300等市场指数**，基准与策略的可交易约束不同。
- 超额收益为策略区间累计收益减去基准区间累计收益，单位为百分点；不是年化 alpha。

### 实验留痕

本地 `data/experiments.sqlite3` 保存最近 50 次成功实验的参数、统一行情快照、报告、行情 SHA256、计算代码 SHA256 和运行时间。该文件已忽略，不提交到 Git。达到 50 次后删除最早的记录；重要实验应导出快照。

复跑使用原行情和参数，运行当前代码；代码发生变化时代码指纹会改变。它不会自动恢复旧版本代码。行情快照可以导出用于核对与备份；当前没有把外部快照上传导入数据库的接口。实验结果与快照不是券商账户、持续模拟账户或审计级不可篡改记录。
